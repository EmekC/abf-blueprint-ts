# @abfc/eslint-plugin

Internal package of abfc, the TypeScript to Blueprint compiler for Abiotic Factor mods. It is published so that `@abfc/cli` can depend on it and is not meant to be used on its own; its API can change between releases.

See [abfc](https://github.com/EmekC/abf-blueprint-ts#readme) for what abfc is and how to install it. MIT license.
